# LinkedIn post drafts

Drafts of posts about building Ingot in the open. Kept in the repository so the
writing stays close to the work it describes, and so a post can be traced back
to the commit and the ADR it came from.

Suggested file naming: `YYYY-MM-DD-short-slug.md`.

`docs/learning-log.md` is usually the better source than the commit history —
the things that broke tend to make the more honest posts.
